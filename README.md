# Weltküche

Rezepte aus allen 197 Ländern der Welt, zum Nachkochen. Kostenlos, ohne Anmeldung, funktioniert auch offline.

**App öffnen:** https://pablobors.github.io/weltkueche/

## Auf dem Android-Handy installieren
1. Den Link oben in **Chrome** öffnen.
2. Unten auf „📲 App installieren“ tippen, oder im Chrome-Menü (⋮) „App installieren“ bzw. „Zum Startbildschirm hinzufügen“ wählen.
3. Die Weltküche erscheint als App-Symbol auf dem Startbildschirm.

## Deine Daten
Kochbuch, Weltreise-Pass, Wochenplan, Bewertungen und Notizen werden nur im Browser deines Geräts gespeichert, nie auf GitHub. Über „💾 Sicherung“ unten auf der Seite kannst du sie als Datei sichern oder auf ein anderes Gerät mitnehmen.
